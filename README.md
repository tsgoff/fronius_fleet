# Fronius Solar.web Fleet - Home Assistant Integration

This is a custom component for Home Assistant to integrate with Fronius Solar.web Fleet.

## Installation

### Manual Installation
1. Copy the `custom_components/fronius_fleet` folder into your Home Assistant's `custom_components` directory.
2. Restart Home Assistant.

### HACS Installation (Optional)
If you have HACS installed, you can add this repository as a custom repository and install it through HACS.

## Configuration

This integration supports the UI configuration flow.

1. Go to your Home Assistant Settings -> Devices & Services.
2. Click "Add Integration" in the bottom right corner.
3. Search for "Fronius Solar.web Fleet".
4. Follow the on-screen instructions to enter your configuration details.
